# 変更可能パラメータ一覧（v2.6）

すべて `src/config.js` にあります。変更したら `npm run build` で `ricochet.js` を作り直してください。

## 部屋 `ROOM`
| 名前 | 値 | 意味 |
|---|---|---|
| L | 11 | x・y方向の半分の大きさ（m）。断面は22 m × 22 m |
| W | 9 | z方向（回転軸）の半分の大きさ（m）。奥行き18 m |
| CENTER_Y | 16 | 観客席から見た部屋の中心の高さ（表示用） |

## 重力シフト `GRAVITY_SHIFT`
| 名前 | 値 | 意味 |
|---|---|---|
| enabled | true | false にすると回転しない（練習用） |
| interval | 30 | シフトの間隔（試合時間・秒）。最初のシフトは30秒の時点 |
| duration | 6 | 90°回るのにかかる時間（秒） |
| warning | 2 | 予告を出す時間（秒） |
| settle | 1 | 回転後の「NEW FLOOR」の時間（秒） |
| floorCos | 0.695 | 面を床とみなす条件（法線と上方向の内積がこの値以上 ＝ 約46°以内） |

## キャッチ `CATCH`（プレイヤー）
| 名前 | 値 | 意味 |
|---|---|---|
| range | 3.0 | 目からディスクの中心までの距離（m） |
| angleDeg | 70 | 照準とディスクの方向のなす角の上限（°） |
| window | 0.8 | ボタンを押してから受け付ける時間（秒） |
| rescue | 0.25 | 早押し・遅押しの猶予（秒） |
| cooldown | 0.5 | 空振りしたあと、次の受付を開けられない時間（秒） |
| suctionTime | 0.1 | 成功時の吸い込み演出の時間（秒）。この間はシュートできない |
| approachSlack | 1.0 | 離れていくディスクでも、この距離以内ならキャッチできる（m） |

## 空中シュートのブレ `AIR_SHOT_SPREAD`（v2.5.2と同じ）
地上 0° / 上昇中 2.5° / 頂点付近 1.2° / 落下中 2.0° / 頂点とみなす範囲：上下の速さ2.0 m/s以内
