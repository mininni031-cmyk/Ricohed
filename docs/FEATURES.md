# 実装済み機能一覧（v2.6）

「確認」の列は、そのことをどう確かめたかを示します。
- **自動**：Playwrightによる自動テスト（[TEST_RESULTS](TEST_RESULTS.md)）
- **画像**：スクリーンショットやレンダー画像を目で確認
- **計測**：バランス検証スクリプト（[BALANCE](BALANCE.md)）

| 分類 | 機能 | 確認 |
|---|---|---|
| 試合 | 3分間の1v1（プレイヤー対CPU）、カウントダウン、結果画面、もう一度／タイトルへ | 自動（#02, #27） |
| 試合 | 得点 1点・2点・3点（反射回数＋1、上限3点） | 自動（#23） |
| 試合 | ポーズ／再開（Esc・ボタン・マウスロック解除・タブ切り替え）。ポーズ中は試合時計も重力の時計も止まる | 自動（#03） |
| 重力シフト | 試合時間で30秒ごとに右へ90°回転（予告2秒 → 回転6秒 → 安定1秒）。重力の強さは一定 | 自動（#16） |
| 重力シフト | 右の壁が新しい床になる。プレイヤー・ディスクが新しい床に着地する。ジャンプは新しい「上」へ | 自動（#17） |
| 重力シフト | 回転中も操作できる。カメラは水平を保ち、急に飛ばない。値が壊れない。部屋の外に出ない | 自動（#18） |
| 重力シフト | 試合中のどの時点でも、体が壁に食い込まない（3分間の試合で最大食い込み0 m） | 自動（#27） |
| 重力シフト | 酔い軽減（周辺を暗くする・視野角を少し狭める）。モーション軽減時は揺れを抑える | 画像 |
| 4面ゴール | 有効な2口は、常に今の床の左右（CYANは左・PINKは右）で、床から2.0 m。4つの向きすべてで確認 | 自動（#20） |
| 4面ゴール | 有効でない口では得点にならない（シャッター＋反射） | 自動（#20） |
| 4面ゴール | 回転中は前のゴールが有効で、回転が終わると切り替わる | 自動（#21） |
| キャッチ | 3.0 m / 70° / 受付0.8秒 / クールダウン0.5秒。地上と空中で同じ | 自動（#06, #11, #13） |
| キャッチ | 連続判定（サブステップの線分で判定） | 自動（#08） |
| キャッチ | 早押し0.25秒・遅押し0.25秒の猶予 | 自動（#09, #10） |
| キャッチ | パネル越しのキャッチは不可。CPUは別のパラメータ | 自動（#12） |
| キャッチ | 成功時だけ吸い込み演出＋CATCH! の表示 | 自動（#07） |
| キャッチ | クロスヘアの緑表示 ＝ 実際の判定 | 自動（#26） |
| キャッチ | デバッグ表示（失敗理由・距離・角度・重力の状態） | 自動（#14） |
| 移動 | WASD・マウス視点・ダッシュ・二段ジャンプ・空中移動70% | 自動（#04, #15） |
| ウォールキック | 壁から0.8 m以内で発動。1回の滞空で空中アクションは1回だけ。回転後も今の重力に対して働く | 自動（#15） |
| ハーフライン | 体は相手陣地に入れない（ディスクは越えられる）。回転が終わると自陣へワープ | 自動（#24, #27） |
| キーパー | 左右の動きだけで、ディスクを追わない。ポーズを付けたモデルの関節から作った3D当たり判定。ゴールの上半分の約3割をカバー | 自動（#22） |

| ディスク | 16 m/s。サブステップ（8 cm以下）で反射。持ち時間7秒（落とした本人は1秒間拾えない） | 自動（#05, #27） |
| CPU | 拾う・守る・キャッチする・シュートする（直接／バンク／ジャンプ）。どの重力の向きでも同じように考える | 自動（#27：3分間でCPUのシュート32本・ゴールあり） |
| 演出 | 試合開始・CATCH!・バウンド数・WALL KICK・BLOCK・GOAL・ARENA SHIFT IN n・GRAVITY SHIFT・NEW FLOOR・試合終了 | 自動（#25）／画像 |

| スマホ | 横画面のタッチ操作（スティック・視点ドラッグ・各ボタン）。キャッチ可能時にCATCHボタンが光る。タップで演出を飛ばせる | 自動（#30） |
