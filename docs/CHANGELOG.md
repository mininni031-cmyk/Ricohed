## v2.6.0（2026-10-14）— ARENA GRAVITY SHIFT（v2.6 マスター指示書）

### 指示書の解釈（実装前に確認した点）
| 項目 | 決めた内容 |
|---|---|
| 回転の軸 | 部屋の**横幅方向（z軸）**を軸に回転。断面を**正方形（22 m × 22 m）**にして、床・左右の端の壁・天井の4面すべてがゴール面になれるようにした |
| ハーフライン | 回転中は無効。**回転が終わった時点で相手陣地にいる人は、自陣のスポーン位置へワープ**。CYANは常に左ゴール、PINKは常に右ゴール |
| キャラクター | Blenderでキーパーを**1体だけ**作り、画像で確認してもらう。**承認されるまでゲームには組み込まない** |

### ARENA GRAVITY SHIFT（新規）
- 試合時間で30秒ごとに、部屋が**右へ90°**回転します（いつも同じ向き）。
  - 2秒前から「ARENA SHIFT IN 2 / 1」が表示されます。
  - 回転は6秒です（smootherstep：始めと終わりで速度0）。その後1秒で安定します（NEW FLOOR）。
- 重力はベクトルとして扱います。**強さは常に15.2 m/s²で一定**で、向きだけが変わります。プレイヤー・CPU・ディスク・キーパーは、すべて今の重力方向に従います。
- 床を判定する条件：面の法線と「上」のなす角が約46°以内のとき（`floorCos 0.695`）、その面を床とみなします。回転中に床が傾きすぎると滑り落ちます。
- 観客席・屋根・照明は世界に固定したままで、**部屋だけが回ります**。
  - カメラの水平線は常に水平です（部屋が自分の周りを回るように見える）。
  - 回転中も操作できます。
- 酔い軽減（初期値ON）：回転中は画面の周辺を暗くし、視野角を少し狭めます。モーション軽減設定では、画面の揺れを抑えます。
- ゴールのお祝い中に回転が始まっていた場合は、最後まで回転してから次のプレーを始めます。回転中は試合時計も進むので、**シフトは常に試合時間30秒ごと**です（3分で5回）。
- 試合終了の時刻に重なるシフトは予告しません。HUDには「FINAL STAGE」と表示します。
- HUDの時計の下に、次のシフトまでの秒数（`SHIFT 12s`）を常に表示します。スマホでも表示されます。

### 4面ゴール（新規）
- 床になりうる4面（±x, ±y）それぞれに、**ゴールの口を2つ**（隣の面寄りに1つずつ）配置しました。合計8口です。これで、どの向きのときも「今の床から2.0 mの高さ」にゴールがあります。
- 有効なのは、**今の床の左右の面にある、床寄りの2口**だけです。CYANのゴールは常に世界の左、PINKのゴールは常に右です。
- 有効でない口にはシャッター（CLOSED）が下ります。そこへディスクが入っても**得点にはならず**、壁として反射します。
- 回転中は前の2口が有効のままで、**回転が終わった瞬間に新しい2口へ切り替わります**。キーパーも同時に移動します（0.3秒の登場アニメーション。その間はセーブしない）。
- ゴールの判定：ディスクの前の縁が面に届いた瞬間（中心が L − 半径 を越えた瞬間）に、開口部の中心から1.45 m以内なら得点です。リングに当たると反射します。

### キャッチを全面的に作り直し
- **地上・空中で同じルール**です。
  - 距離3.0 m（目→ディスク中心）、照準との角度70°以内
  - 受付時間0.8秒、空振り後のクールダウン0.5秒
- **連続判定（スイープ）**：最後のサブステップでディスクが通った線分のうち、目にいちばん近い点で判定します。高速のディスクがフレームの間をすり抜けることはありません。
- **0.25秒の猶予を前後に**設けました。
  - 早押し：ディスクがまだ飛んでいないとき（CPUが構えている間など）に押した場合、0.25秒間は入力を保持します。
  - 遅押し：0.25秒前までキャッチできた状態だったディスクは、押した瞬間に取れます（LATE SAVE）。
- パネル越しのキャッチはできません。真後ろ・真横のキャッチもできません（角度で判定）。離れていくディスクは1 m以内のときだけキャッチできます。
- 成功したときだけ、ディスクが0.1秒で手元へ吸い込まれる演出が入ります。空振りでは吸い込みません。
- CPUには別のルールを適用します（2.6 m / 60° / 0.5秒 / クールダウン0.8秒）。反応の遅れや成功率は、従来どおり難易度ごとに変わります。
- **デバッグ表示**（タイトルのチェック、または `?debug=1`）では、次の内容を日本語で表示します。
  - 失敗した理由（距離が遠い／角度がずれている／離れていくディスク／パネルの陰／クールダウン中…）
  - 距離・角度・受付時間の残り
- クロスヘアの緑表示とキャッチ本体は**同じ関数**（`evalCatch`）を使っています。テストで、60フレームすべてで一致することを確認しました。
- 廃止したもの：CATCH ASSIST（STANDARD / LEGACY）、地上と空中で別のキャッチ判定。

### ディスク
- 速度を21 m/sから**16 m/s**に下げました。今後「速いシュート」を追加できるよう、`SHOT_SPEEDS` を用意しています。

### 部屋・パネル
- 部屋を**22 m × 22 m の正方形断面 × 奥行き18 m**に作り直しました（v2.5.2は32 m × 20 m・天井8 m）。
  - 回転でどの面も床になるため、天井（＝反対側の面）は床から22 mあり、ジャンプでは届きません。
- 反射パネルは**固定**にしました（v2.5.2の毎秒8°の回転は廃止）。CYAN側とPINK側で配置は非対称です。
  - パネルは部屋に固定なので、回転すると床から近くなったり遠くなったりします。
- パネルの見た目と当たり判定は、同じデータから作っています。テストで、位置・角度・大きさの差は0であることを確認しました。

### キーパー
- 当たり判定を、**ポーズを付けたモデルの関節から測った3Dカプセル**に変えました（両腕・両脚・胴・頭の6つ）。見た目と判定のずれはありません。
- 両腕を上げたYスタンスで、全体を1.25倍にしました（手の先が床から約2.4 m）。ゴールの上半分の約3割をカバーするので、空中から高いコースを狙う意味があります。
- 動きは左右だけです（ディスクを追いかけません）。回転後は新しい床に立ちます。

### ウォールキック・ハーフライン
- ウォールキックは「**今の重力に対して壁である面**」（法線と上方向の内積が0.5未満）で発動します。キックの上向きの速度も、今の「上」に向きます。
- ハーフラインは部屋と一緒に回り、回転中は無効になります。回転が終わったら、相手陣地にいる人をワープさせます（PLAYER_WARPED）。

### モーショングラフィックス（新規）
- 次の場面に演出を入れました。
  - 試合開始（チームバナーが左右から入る）
  - CATCH!（2重リングが収束）
  - バウンド数（RICOCHET / DOUBLE / RIM!）
  - WALL KICK（スピードライン）
  - BLOCK!
  - GOAL（チームカラーの帯）
  - ARENA SHIFT IN n / GRAVITY SHIFT / NEW FLOOR
  - 試合終了
- 表示場所（スロット）ごとに1つだけ表示し、重なりません。Enter / Tab、またはスマホでは大きな見出しをタップすると飛ばせます。それ以外の部分は、タッチを視点操作へ通します。
- モーション軽減設定、またはOSの「視差効果を減らす」がオンのときは、フェードだけになります。

### スマホ
- キャッチできるときは、CATCHボタンが緑に光ります。
- 案内の文章をタッチ操作向けにしました。
- 次のシフトまでの秒数を表示します。

### オンライン対応を見据えた構成（[詳細](ONLINE_ARCHITECTURE.md)）
- シミュレーションのモジュール（gravity / goals / athlete / physics / catch / cpu / keeper / events / rng）は、DOMや描画に依存しません。
- 固定ステップは1/120秒です。乱数はシードで決まります。各システムに `snapshot()` があります。
- 指示書で指定された名前のイベント（MATCH_STARTED, DISC_THROWN, DISC_CAUGHT, …）をイベントバスで流します。UI・音・観客はそれを受け取るだけです。
- 描画の結果をシミュレーションが読む箇所をなくしました。
  - CPUが持つディスクの位置は、骨格ではなく論理的な手の位置で決めます。
  - キャッチの吸い込みタイマーは、シミュレーション時間で進めます。

### 不具合の修正（v2.6の作業中に見つけたもの）
- ゴールの判定面がディスクの中心で計算されていたため、口に入っても得点にならないことがありました（v2.6の新しい部屋で発生）。前の縁で判定するように修正しました。
- 他の体と押し合ったあとに、カプセルが壁へ最大13 cm食い込むことがありました。最後にもう一度、面から押し出すようにしました。
- 持ち時間（7秒）で落としたディスクを、その場ですぐ拾い直せました。落とした本人は1秒間拾えないようにしました。
- キーパーの当たり判定を測るとき、部屋のオフセットが拡大率に混ざり、判定が約2倍の高さになっていました。修正しました。
- スイープ判定で、ディスクが真横を通過する瞬間（速度と向きのなす角が90°）を「離れていく」と誤判定していました。修正しました。
