## 仕様として意図的に変えた点・制限
- 部屋の断面が正方形（22 m）なので、天井（反対の面）はジャンプでは届きません。v2.5.2の「二段ジャンプで天井に届く」遊びはなくなりました。
- 回転は常に右回りなので、回転のたびに部屋の中の人は「新しい床とCYAN側の壁の角」へ滑り落ちます。そのため、**回転のたびにPINK（CPU）側がワープしやすい**という偏りがあります（3分間の試合で5回中5回ワープ）。公平性の調整は[ROADMAP](ROADMAP.md)に入れました。
- キーパーは移動した直後0.3秒間、セーブしません（登場アニメーションに合わせています）。
- 自動テストの対象を、v2.6の仕様に合わせて作り直しました。v2.5.2のテストのうち、次の項目はv2.6では自動テストしていません。
  - ダッシュの使用条件
  - 空中移動の慣性の数値
  - CPU難易度ごとの違い
  - BGM / SEの切り替え
  - 観客の演出
