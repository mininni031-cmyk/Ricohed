## 次の開発順（提案）
1. **キーパー1体目のフィードバックを反映**し、承認をもらう（見た目の修正だけなら短時間）。
2. **実機プレイテスト**（PC・スマホ各1台）：酔い、回転中の操作、キャッチの感触を確認する。必要なら、`GRAVITY_SHIFT.duration`（6秒）や酔い軽減の強さを調整する。
3. **ワープの偏りの調整**：次のどれかを選ぶ。
   - (a) 回転の向きを交互にする
   - (b) 回転中だけ体を新しい床へ「吸着」させ、滑り落ちを減らす
   - (c) 回転の直前に、両チームを自陣の中央へ寄せる

   指示書は「常に右回り」なので、(b) を推奨します。
4. **キャラクターのGLB統合**：メッシュの結合、ポーズの移植、当たり判定の測り直し、CYAN版の作成。
5. **Matchクラスの分離**と、ヘッドレス（Node）でのシミュレーションテスト。
6. **オンライン対戦の試作**：WebSocketとサーバー権威（入力 → tick → snapshot / イベント）、自分のキャラクターの予測、キャッチのラグ補償。
7. 速いシュート（`SHOT_SPEEDS`）や新しいパネル配置など、遊びの追加。
